Now I build the interface itself, in the browser, so the motion, spacing and feel ship exactly as designed instead of getting lost in a handoff. Based in Calgary → [ebere.design](https://www.ebere.design)

## What I've built

- 🎚️ [feel-skill](https://github.com/eb-ekeledo/feel-skill): turns feel words like "snappy" or "calm" into real motion and spacing values, for designers working in Claude
- 🧾 [state-sheet-skill](https://github.com/eb-ekeledo/state-sheet-skill): lays out every state of a component on one review sheet, so nothing ships half-designed
- 📏 [taste-lint](https://github.com/eb-ekeledo/taste-lint): checks a live interface against its DESIGN.md and flags type, spacing and color drift
- 🧪 headless-playground: a daily design engine and a growing set of interactive craft pieces
